# Tiny11 Builder: руководство пользователя (русская редакция)

Краткое русское руководство. Полная английская версия — `usage.md`; технический отчёт
локализации — `REPORT_RU.md`.

## Что делает приложение

Создаёт уменьшенный установочный ISO Windows 11 из официального образа: монтирует образ,
удаляет выбранные компоненты и политики, сжимает установочный образ и собирарует загрузочный
ISO с помощью oscdimg. Исходные файлы никогда не изменяются; вся работа ведётся в отдельной
рабочей области (NTFS, обычно 40–70 ГиБ свободно).

Шаги мастера: **Добро пожаловать → Образ Windows → Удаление компонентов → Параметры сборки →
Обзор → Сборка**. Навигация — кнопкой действия внизу справа («Начать», «Далее», «Обзор»,
«Продолжить», «Сборка») и списком шагов слева; «Назад» и «Безопасная отмена» — сверху.

## Режимы сборки

- **Tiny11** — оригинальный набор удалений ntdev: убирает рекламные и необязательные
  приложения, сохраняет Windows Update, Defender и восстановление.
- **Tiny11 Core** — дополнительно необратимо усечатает компоненты, удаляет WinRE, отключает
  Windows Update и Defender. Только для изолированных тестовых ВМ: образ не обслуживается.
  Требуется отдельное подтверждение рисков.
- **Свой набор** — ручной выбор групп удалений и отдельных компонентов (включая защищённые
  через «Показать все компоненты…»; удаление защищённых элементов может сделать образ
  незагружаемым, требуется отдельное согласие).

## Турборежим и уменьшение образа

Турборежим пакетирует удаления компонентов/возможностей в пакетные команды DISM и использует
быстрый промежуточный рабочий образ (Core и «Быстрый WIM»); потребляет больше ЦП и места,
итоговое сжатие остаётся выбранным. Сжатие: **Recovery ESD** (меньше размер), **Максимальный
WIM** (проще обслуживать), **Быстрый WIM** (скорость). Дополнительные переключатели: удаление
избыточных данных образа, исключение данных установки .NET 3.5 (sources\sxs), компактная
установка, включение .NET Framework 3.5, локальная учётная запись, сохранение рабочих файлов.

## Совместимость сборок Windows

Поддерживаются клиентские образы Windows 11 22H2 и новее (x64/ARM64), включая Insider/Canary.
Инструменты образа (DISM/oscdimg) подбираются автоматически: системный DISM, при несоответствии
версии — DISM/oscdimg из Windows ADK (скачиваются и проверяются по подписи/хешу). Неизвестные
новые сборки могут потребовать свежий ADK; Windows 10 как хост поддерживается при совместимых
инструментах.

## Сборка и запуск (для разработчика)

Требуется Windows 10/11 x64 или ARM64, .NET SDK 8 и комплект Windows App SDK 2.5.1
(восстанавливается автоматически). Публикация:

```
dotnet publish src/Tiny11Builder.App/Tiny11Builder.App.csproj -c Release -p:Platform=x64
```

Запуск — `Tiny11Builder.exe` от имени администратора (нужен для монтирования образов).
Готовые русские архивы собираются из официального релиза апстрима
(оверлей-подход) и публикуются в Release этого репозитория.

## Журналы, рецепты и восстановление

- Каталог задачи: `<рабочая область>\tiny11-<дата>-<время>\` — там `build.log` (полный журнал
  операций DISM и движка), `recipe.json` (выбор и пути), `report.json` (итог: хеш, размеры,
  предупреждения), `operations.json`/`timings.json` (история и длительности), `checkpoint.json`
  (проверенный прогресс для возобновления).
- **Продолжить сборку** — возобновляет прерванную сборку с сохранённого прогресса (выбор
  удалений замораживается; меняются только путь результата, инструменты, сжатие и очистка).
- **Восстановить рабочую область** — очищает прерванную задачу без сохранённого прогресса
  (отменяет монтирование, удаляет подготовленный носитель; журналы и исходник сохраняются).
  Задачу с сохранённым прогрессом восстановление отказывается удалять без явного подтверждения.
- Рецепт можно сохранить/загрузить кнопками на шаге «Компоненты» (выбор и локальные пути,
  без носителей и учётных данных); после загрузки риски Core/экспертных удалений подтверждаются
  заново.
- Журнал русской локализации (обходы, замены, иконка, ремонт кодировок, ошибки):
  `%LOCALAPPDATA%\Tiny11Builder\ru-localization.log`.

## Отмена и безопасность

«Безопасная отмена» останавливает операцию в следующей безопасной точке: активная операция DISM
доживает, монтирование корректно отменяется, прогресс и журналы сохраняются. Исходный образ не
изменяется никогда. Диалог отмены остаётся открытым до фактической остановки и показывает, чем
закончилась операция.

## Тесты

`dotnet test tests/Tiny11Builder.Core.Tests` — тесты движка и winui-независимой логики
приложения (отмена, возобновление, версии инструментов, заголовки WIM, пакеты обслуживания).
В русской редакции тесты переведены синхронно с кодом и проходят/падают идентично английским
(на Linux часть падает из-за Windows-API в обеих редакциях).

## Оригинальные скрипты PowerShell

`tiny11maker.ps1` и `tiny11Coremaker.ps1` (классические скрипты ntdev) сохранены без перевода
как справочные; продукт-приложение WinUI их функционально покрывает.
