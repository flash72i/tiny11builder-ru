=====================================================================
 Tiny11 Builder WinUI 0.1.1 — РУССКАЯ ЛОКАЛИЗАЦИЯ (x64)
=====================================================================

Это оригинальная сборка Tiny11 Builder WinUI 0.1.1 от ntdevlabs
(https://github.com/ntdevlabs/tiny11builder/releases/tag/winui-v0.1.1),
полностью русифицированная без изменения логики работы программы.

УСТАНОВКА
---------
1. Полностью замените содержимое прежней папки приложения файлами из
   этого архива (как предписывает оригинальный релиз при обновлении).
2. Запустите Tiny11Builder.exe и подтвердите запуск от имени
   администратора.
3. Windows-образы и сохранённые файлы сборок не затрагиваются.

ЧТО ИЗМЕНЕНО
------------
* Tiny11Builder.dll, Tiny11Builder.Core.dll — все тексты интерфейса,
  диалогов, статусов, журнала и отчётов заменены на русские:
  1049 строковых литералов в IL-коде (441 + 608). Ещё 44 литерала
  внутри компиляторных деревьев переключения (BuildProgressText.Phase/
  Range и фильтр этапов) сохранены английскими намеренно: на входе
  этих методов добавлен нормализатор <RuPatch>.MapStage (русское имя
  этапа -> внутреннее английское), поэтому логика прогресса работает
  с русскими названиями этапов без изменений.
* Tiny11Builder.Ru.dll (новый файл) — слой локализации, переводящий
  тексты, скомпилированные в XAML (MainWindow.xbf внутри
  Tiny11Builder.pri): 147 строк. Применяется при запуске окна.
* Tiny11Builder.deps.json — добавлена запись Tiny11Builder.Ru.dll.
* Все остальные файлы — байт-в-байт оригиналы из официального ZIP.

ЧТО СОЗНАТЕЛЬНО НЕ ПЕРЕВОДИЛОСЬ (важно для корректной работы)
-------------------------------------------------------------
* Названия Tiny11 / Tiny11 Core — имена режимов (бренды).
* Значения, сравниваемые с выводом DISM: "Installed", "Not Present",
  "Disabled with Payload Removed" и др.
* Идентификаторы пакетов, имена файлов (job.json, install.wim, ...),
  пути реестра, ключи DISM (/Remove-Capability и т.п.).
* Названия языков ISO в каталоге Microsoft ("English International"
  и др.) — по ним идёт поиск на сервере Microsoft.
* Внутренние ключи этапов и контрольных точек ("stage:Commit",
  "committed" и т.п.).
Перевод выполнен ЕДИНЫМ словарём для обеих сборок, поэтому все
внутренние сопоставления строк (этапы -> прогресс, фильтры категорий,
статусы) продолжают работать точно как в оригинале.

ВЕРСИЯ ЛОКАЛИЗАЦИИ: rev.3 (15.10.2026)
---------------------------------------
ИСПРАВЛЕНО В REV.3 (по отзыву с реальной машины)
* Пустой список групп удаления на шаге «Компоненты»: фильтр читал текст
  пункта ComboBox («All») ДО того, как слой локализации переводил его в
  «Все», тогда как сравнивающий литерал в коде уже был русским — фильтр
  не находил ни одной категории. Хук локализации перенесён в конструкторе
  окна на точку СРАЗУ ПОСЛЕ InitializeComponent(), до любой логики,
  читающей тексты элементов. Список снова полный.
* «Иероглифы» в названиях редакций образа (Windows 11 Домашняя и т.п.):
  сторонний дефект оригинала — DISM печатает имена в OEM-кодировке
  (CP866 в русской Windows), а приложение читало поток в ANSI (CP1251).
  В русскую сборку внедрена установка StandardOutputEncoding/
  StandardErrorEncoding = OEM-кодировка системы для всех запускаемых
  инструментов (DISM/oscdimg): имена редакций, пакеты и журнал читаются
  корректно на любом языке системы.
* Иконка с триколором теперь ВШИТА в сам Tiny11Builder.exe (PE-ресурсы
  RT_ICON/RT_GROUP_ICON, 9 размеров 16-256, старые ресурсы версии и
  манифеста сохранены байт-в-байт). Ярлыки создавать не нужно: значок
  виден в проводнике, на рабочем столе, в панели задач и Alt-Tab.
  Файлы ярлыков/ico из архива убраны как лишние.
* REV.3.1: исправлена ошибка внедрения кода чтения OEM-кодировки
  (некорректная IL-сигнатура вызова установки StandardOutputEncoding
  приводила к MissingMethodException при первом запуске DISM). Добавлены
  автоматические проверки внедряемых IL-ссылок и прогон внедрённого кода
  ProcessRunner на исполняемом тесте; внедрённый кодерустойчив: при
  недоступности кодовой страницы используется кодировка по умолчанию
  (поведение оригинала).
* REV.3.2: самовосстановление «иероглифов» в отображаемых текстах
  (имена редакций образа и прочие строки вывода DISM): детектор
  мусорных маркеров + перебор пар перекодировок CP1251/CP866/UTF-8
  с выбором наиболее «русского» результата. Первые 5 исправлений
  попадают в ru-localization.log строками "mojibake repaired: [было] -> [стало]"
  — это даст точную пару кодировок для постоянного исправления в ядре.
* Журнал %LOCALAPPDATA%\Tiny11Builder\ru-localization.log остаётся
  (rev.2): проходы локализации, замены, иконка, все ошибки.

ПРОВЕРКИ, ВЫПОЛНЕННЫЕ ПРИ СБОРКЕ
--------------------------------
* Контрольные суммы оригинальных ZIP сверены с опубликованными.
* После модификации: полное чтение IL обеих сборок (2453 метода),
  метаданные валидны; ни одна критическая строка не затронута.
* Дифференциальные юнит-тесты проекта (оригинал vs русская версия).

Внимание: сборка ISO по-прежнему требует Windows 10/11 x64, прав
администратора и ~40-70 ГиБ свободного места на NTFS. Как и оригинал,
сборка не подписана — SmartScreen может показать предупреждение.

Русификация выполнена поверх релиза winui-v0.1.1 (commit d060813).
