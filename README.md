# Tiny11 Builder WinUI 0.1.1 — полностью русский исходный код

Полный исходный код Tiny11 Builder WinUI 0.1.1 с полностью русским интерфейсом: окна, диалоги,
статусы, журнал и тесты. Логика программы не изменена; строки, которые читают внешние системы
Windows (DISM, реестр), оставлены английскими намеренно.

Перевод, инструменты сборки и проверки сделаны с помощью ИИ (Qwen) и проверены дифференциальными
тестами. Готовый архив x64 — в Release; пересборка — `build.sh` (любая ОС) или `dotnet publish`
(Windows). Оригинал — ntdevlabs, апстрим без лицензии, правовая заметка ниже.


Оригинальный английский README апстрима сохранён как `README.upstream.md`,
атрибуция — в `NOTICE.md` и разделе «Правовая заметка» ниже.

## Состав

| Путь | Что это |
|---|---|
| `src/` | приложение WinUI (`Tiny11Builder.App`) и движок (`Tiny11Builder.Core`) — **строки переведены**: C#-литералы (≈900) и XAML-атрибуты (177) |
| `tests/` | юнит-тесты движка и логики приложения — переведены синхронно с кодом (падают/проходят так же, как английские) |
| `overlay/` | `Tiny11Builder.Ru` — рантайм-слой: перевод XAML-текстов из `MainWindow.xbf` (147 пар), журнал `ru-localization.log`, иконка-триколор, ремонт кодировочного мусора вывода DISM (rev.3.3-wip) |
| `dict/` | единый словарь EN→RU (1021 запись) + наборы для IL/XAML/тестов |
| `tools/` | IL-вейвер (Mono.Cecil), PE-иконкор, упаковщик, парсеры, исполняемый bind-тест |
| `docs/` | `REPORT_RU.md` — полный технический отчёт (аудит, метод, верификация, ревизии); `README_RU.txt` — памятка из готовых архивов; `usage.ru.md` — краткое руководство пользователя |
| `icon/` | иконка-триколор (ICO, 16–256 px) |
| `build.sh` | воспроизводимая сборка готовых ZIP **из официального релиза** (оверлей-подход: бинарии апстрима не перераспределяются) |

## Два способа получить русскую программу

1. **Собрать из этого репозитория (нужна Windows 10/11 + VS 2022 / .NET SDK 8 с WinUI):**
   ```
   dotnet publish src/Tiny11Builder.App/Tiny11Builder.App.csproj -c Release -p:Platform=x64 -p:RuntimeIdentifierOverride=win-x64
   ```
   XAML-тексты уже русские в разметке; оверлей `Tiny11Builder.Ru` в этом сценарии не обязателен
   (он нужен для варианта 2), но его подключение добавляет журнал, иконку и ремонт кодировок.
2. **Наложить оверлей на официальный релиз (любая ОС, бинарии апстрима скачиваются сами):**
   ```
   ./build.sh
   ```
   Получится `out/Tiny11Builder-0.1.1-ru-win-x64.zip` (+arm64) с контрольными суммами —
   именно так собраны архивы в Release этого репозитория.

## Тесты

```
dotnet test tests/Tiny11Builder.Core.Tests
```
На Windows проходят так же, как английские оригиналы; на Linux часть тестов падает
из-за Windows-API (одинаково в английской и русской версиях — проверено дифференциально,
см. `docs/REPORT_RU.md`, раздел 3).
