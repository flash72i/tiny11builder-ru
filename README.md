# Tiny11 Builder WinUI 0.1.1 — русская локализация (overlay + воспроизводимая сборка)

Полная русификация интерфейса [Tiny11 Builder WinUI 0.1.1](https://github.com/ntdevlabs/tiny11builder/releases/tag/winui-v0.1.1)
без изменения логики работы программы. Этот репозиторий содержит **только собственные
материалы локализации** (MIT, см. LICENSE) и скрипты воспроизводимой сборки; код и бинарные
файлы апстрима не перераспределяются (см. «Правовая заметка»).

## Что здесь лежит

| Путь | Назначение |
|---|---|
| `overlay/` | `Tiny11Builder.Ru.dll` — рантайм-слой перевода XAML-текстов (147 пар), лог `ru-localization.log`, иконка-триколор, самовосстановление кодировочного мусора |
| `dict/` | единый словарь EN→RU (1021 запись) и сгенерированные наборы для IL/XAML/тестов |
| `tools/Weaver/` | IL-вейвер на Mono.Cecil: замена `ldstr` (441+608), хук `Attach` после `InitializeComponent`, префиксы `MapStage` для компиляторных string-switch деревьев, внедрение OEM-кодировки чтения вывода DISM, bind-check внедрённых ссылок |
| `tools/peicon.py` | вшивание иконки в PE-ресурсы apphost-EXE (RT_ICON/RT_GROUP_ICON) |
| `tools/bindtest/` | исполняемый bind-тест внедрённого кода `ProcessRunner` |
| `tools/pack.py`, `strip_rsrc.py`, `patch_deps.py`, `translate_cs2.py`, `tools_dump.py` | упаковка/верификация/вспомогательные парсеры |
| `app-logic-ru/` | переведённые копии winui-независимых файлов логики приложения (`Choices.cs`, `OperationFlow.cs`) — для дифференциальных тестов |
| `docs/` | `REPORT_RU.md` — полный технический отчёт (аудит, метод, верификация, ревизии), `README_RU.txt` — пользовательская памятка из архива |
| `icon/` | иконка-триколор (ICO, 9 размеров) |
| `build.sh` | воспроизводимая сборка обоих архитектурных архивов из официального релиза |

## Быстрый старт

```bash
./build.sh          # скачает официальный релиз, сплетёт, вшьёт иконку, упакует out/*.zip + .sha256
```

Требуется .NET SDK 8 (WinUI-проекты собираются кросс-платформенно через
`EnableWindowsTargeting`) и Python 3. Готовые архивы ревизий прилагаются к Release этого
репозитория (по решению владельца).

## Метод в двух абзацах

Текст приложения живёт в трёх хранилищах: XAML-литералы внутри `MainWindow.xbf`
(в `Tiny11Builder.pri`), IL-литералы `Tiny11Builder.dll` и `Tiny11Builder.Core.dll`.
IL-литералы заменены единым словарём (Mono.Cecil, `ldstr`), причём строки-ключи логики
(имена этапов, категории, статусы, префиксы журнала) переведены идентично во всех сборках,
а компиляторные string-switch деревья (`BuildProgressText.Phase/Range`, фильтр этапов)
сохранены английскими и получают нормализатор RU→EN на входе. XAML-тексты переводятся
рантайм-слоем `Tiny11Builder.Ru.dll` (обход дерева элементов с защитой от повторных
посещений, бюджеты прохода, журнал, иконка, ремонт кодировочного мусора вывода DISM).
Строки, сравниваемые с внешними системами (состояния DISM, языки каталога Microsoft,
имена пакетов/служб/реестра, regex-паттерны, внутренние id), не переводятся — полный
перечень в `docs/REPORT_RU.md`, раздел 1.4.
